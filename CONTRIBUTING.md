# Contributing

Install `.[dev]`, run `python -m pytest -q`, and run the browser check for UI changes. Keep conversion local, offline and CPU-only. Add fixture-based tests for bug fixes. Include measured quality and performance changes for tracing modifications; don't optimize only simple synthetic examples.

Use compatible open-source dependencies and include notices. Never commit private artwork or uploaded samples without permission. Follow SECURITY.md for reporting concerns, and avoid attaching sensitive images to public issues. The repository is https://github.com/DylanMartinLSC/TraceGarden.
