# Contributing

Install `.[dev]`, run `python -m pytest -q`, and run the browser check for UI changes. Keep conversion local, offline and CPU-only. Add fixture-based tests for bug fixes. Include measured quality and performance changes for tracing modifications; don't optimize only simple synthetic examples.

Use permissively licensed dependencies and include notices. Never commit private artwork or uploaded samples without permission. Report security concerns privately to the future repository maintainer rather than attaching sensitive images to public issues. The project has no published security contact or public repository yet.
