# Changelog

## Unreleased

- Selectable High Quality mode preserves finer detail in the studio, batch jobs, API and CLI. Fast remains the default.
- Quality settings persist in projects; completed results explain applied enhancement, unsupported input or bounded-work fallback. Explicit fine-tuning and resource limits are retained.

## 0.3.0 — 2026-10-30

- Native CPU shared-curve engine, subpixel graph fitting, whole-component geometry, varying alpha and automatic palette/type selection.
- Rotated rounded rectangles and rounded/stretched stars; individual and bulk corner radius preview, sharpening and parametric shape editing.
- Background keep/remove correction brushes, symmetry detection and automatic/manual repeated-shape normalization.
- Wipe/outline/fullscreen/actual-size inspection, desktop SVG clipboard and file drag payloads.
- All ten export formats, quadratic/cubic/polyline compatibility, grouping/drawing styles and exact elliptical DXF arcs.
- Explicit memory/time budgets, large-source JPEG draft decoding, larger portable projects and all-format CLI export.
- Installable Windows, macOS ARM/Intel and Linux builds with real clipboard round trips and packaged-job/export checks in CI.
- Expanded known-vector corpus, commercial public-demo comparisons, memory/complexity measurements and editor race regressions.

## 0.2.0 — 2026-10-30

- Isolated tracing workers, bounded job queue, cancellation, timeout, expiry and shutdown cleanup.
- Save/open portable project documents, local browser autosave and recovery.
- Source crop, rotation, mirroring, contrast, ICC-to-sRGB conversion, custom palettes and brush corrections with undo.
- Shared-boundary coverage tracing, cutout tracing, fitted elliptical/circular arcs, rounded rectangles and polygon outlines; conditional linear-gradient fitting and uniform-region opacity.
- Multi-selection, join/subtract/intersect, contour splitting, simplification, direction reversal and layer order.
- Polygon/open-line pen, editable polygon nodes and Bézier controls; undo/redo and keyboard shortcuts.
- Vector PDF and PostScript gradients, PDF-compatible AI output, alpha-aware PNG export, physical sizes, generic CMYK PDF, DXF circular arcs/cubic splines or polylines.
- Expanded regression, browser and job lifecycle tests; memory/speed/quality benchmark runner.

## 0.1.0 — 2026-10-28

Initial local CPU studio with presets, batch tracing, color replacement, deletion/undo, preview and exports.
